# LawMart 2.0 — Phase 1

This package is a complete GitHub Pages replacement based on the approved navy/gold LawMart mockup.

## Phase 1 changes
- Rebuilt the homepage from clean HTML/CSS rather than cropping the mockup image.
- Added a real vector LawMart logo and square LM cart icon.
- Added a scalable custom SVG hero illustration; the speech bubble is a separate HTML element and disappears on small screens.
- Added one consistent line-icon style across homepage benefits, consultation paths, trust points, services, and value cards.
- Added the Fast / Flat-Fee / Professional positioning and evening/weekend appointment messaging.
- Added the consultation-choice cards: free phone consultation, $50 office reservation, start documents, existing invoice.
- Preserved the working Formspree endpoint, GA4 configuration, pricing pages, service-specific intake forms, office details, Imigração Brasileira, CNAME, sitemap, privacy page, and resources.
- Updated favicon and web app icon.

## Upload
Extract this ZIP and upload all files/folders inside it to the root of the GitHub repository, replacing existing files.

## Stripe assets
Use `assets/brand/logo-1600.png` for a horizontal brand logo and `assets/brand/icon-512.png` for a square icon.

## Phase 2 suggestion
Apply the same design system to the LawMart service pages, pricing page, resources, privacy/thank-you pages, and 404 page. Imigração Brasileira should remain its own visual brand.
