# LawMart 2.0 Phase 2.2 — Appointment Scheduling

This release integrates Cal.com scheduling into the LawMart website.

- Free phone consultation: Cal.com booking flow, no payment.
- In-person consultation: client chooses an available time first, then completes the $50 Stripe payment configured inside Cal.com before the appointment is confirmed.
- $500 Divorce, Wills & Trusts, and Record Sealing Stripe Payment Links remain available without scheduling first.
- Existing Formspree consultation/intake forms remain available as an alternate lead path.
- Imigração Brasileira remains visually and operationally separate.
