# LawMart 2.0 - Phase 1.1 Visual Refinement

This release refines the Phase 1 homepage implementation.

Changes:
- Replaced the earlier simplified vector hero with a warmer illustrated hero treatment based on the approved LawMart mockup direction.
- Removed the separate speech-bubble overlay from the live homepage.
- Rebuilt the three Why LawMart cards to keep icons, headings, and body copy fully contained.
- Added consistent card height, padding, shadows, rounded corners, icon tiles, and gold bottom accents.
- Preserved Formspree, GA4, custom domain, service pages, pricing, sitemap, and Imigracao Brasileira.
