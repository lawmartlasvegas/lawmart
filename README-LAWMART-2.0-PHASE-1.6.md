# LawMart 2.0 Phase 1.6

This release replaces the Phase 1.5 hero artwork with the approved standalone LawMart hero image and changes the hero frame to the artwork's native 3:2 aspect ratio so the speech bubble, clipboard, representative, and service binders display without cropping.

All existing forms, analytics, service pages, custom domain configuration, and Imigracao Brasileira content are otherwise preserved.
